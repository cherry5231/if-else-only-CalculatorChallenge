# If-Else Calculator Challenge

This project is a basic calculator built entirely using `if-else` statements.
It is intentionally designed this way to explore how far conditional logic can be extended without using loops or external libraries.

---

## Overview

The calculator currently supports operations (`+`, `-`, `*`, `/`, `%`) for up to 5 values (`a, b, c, d, e`) with limited bracket handling.

This repository is meant to be extended and improved.

---

## What You Can Do

Contributors are encouraged to:

* Extend support beyond 5 variables (e.g., `f, g, h...`)
* Add more valid bracket combinations
* Fix existing logical and indentation issues
* Improve the structure while keeping the same approach

---

## Rules

To keep the challenge meaningful, follow these constraints:

* Do not use loops (`for`, `while`)
* Do not import any libraries
* Do not use built-in shortcuts like `eval()`
* Do not modify existing print statements
* Do not completely rewrite the program

You can only build on top of the current logic and improve it.

---

## Known Issues

Some parts of the current implementation are intentionally left imperfect:

* Indentation inconsistencies
* Incorrect or inconsistent `%` (modulo) handling
* Repetitive logic in multiple sections

These are part of the challenge and should be addressed in contributions.

---

## Contribution Guide

1. Fork the repository
2. Make your changes following the rules
3. Submit a Pull Request with a clear explanation

---

## Notes

This is not meant to be an optimized calculator.
The goal is to test problem-solving using limited constructs and see how far the logic can be pushed.
